Safety and method note: Only verified database measurements are screened. Drinking-water screening checks available pH, TDS and turbidity indicators; swimming screening checks available pH, dissolved oxygen and BOD indicators. The current sensor schema does not store E. coli / fecal-coliform results or the full chemical test panels required for clearance. A screening result must never be treated as proof that water is safe. Follow current official advisories and accredited laboratory results.

  • Check the browser console for frontend errors.
  • If a table is empty, verify that the corresponding backend API returns data.
